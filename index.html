What the $497 diagnostic inspects

This is a bounded review of one recent inbound lead flow—not a full CRM archaeology project, and not an accusation that agents failed to call.

  • One lead source at a time
  • One recent export, typically the last 30 days, up to 500 records
  • Created date, source, assigned owner, and status on every file
  • First-response timing and next-action gaps only where activity or task fields exist
  • REVIEW_REQUIRED only if your team names a review-age threshold
  • Everything else labeled cannot verify or age-and-status only

What you hold on Monday

1. Marked Lead Window

A CSV of the reviewed cohort. A label that says REVIEW_REQUIRED means the record exceeds your confirmed threshold, not ours. “Sat” never means “was never called” unless the export contains a qualifying activity timestamp.

2. Ownership & Verifiability Summary

One page of counts your file can support: owners, open status, age, missing response history, and whether a team threshold was supplied.

3. Callback-Clock Rule Sheet

The trigger, required CRM record, deadline, fallback, and manager view going forward. This file does not require historic call times.

This label identifies an open record that requires review; it does not mean the assigned agent failed to call, because the supplied export contains no activity timestamps or contact-history data.
